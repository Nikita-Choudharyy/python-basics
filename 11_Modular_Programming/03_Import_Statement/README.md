# 📥 Import Statements in Python

Welcome to the **Import Statements in Python** section of this repository.

Import Statements are one of the most important features of Python. They allow us to reuse existing code instead of writing everything from scratch.

Python provides hundreds of built-in modules and also allows us to create our own modules and packages. Using import statements, we can access functions, classes, variables, and other objects from these modules whenever required.

In this notebook, you will learn different ways to import modules and packages, understand how Python processes imports internally, and follow best practices used in professional Python development.

By the end of this notebook, you will be able to confidently use import statements in your own Python projects.

# ✅ Best Practices

- Import only the modules you need.
- Prefer explicit imports over wildcard imports.
- Use meaningful aliases (`np`, `pd`, `plt`, etc.).
- Organize imports according to PEP 8.
- Remove unused imports.
- Avoid `from module import *` in professional projects.
- Write clean and readable import statements.
