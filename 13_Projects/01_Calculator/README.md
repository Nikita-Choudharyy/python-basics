# 🧮 Calculator

A simple command-line calculator built using **pure Python**.

This mini project is designed to practice fundamental Python programming concepts by building a small but complete application.

---

## 🎯 Project Objective

The goal of this project is to build a calculator that can perform basic arithmetic operations through a simple menu-driven interface.

The calculator supports:

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Exit

---

## ⚙️ Features

### ➕ Addition

Adds two numbers.

Example:

```text
10 + 5 = 15
```

### ➖ Subtraction

Subtracts the second number from the first.

```text
10 - 5 = 5
```

### ✖️ Multiplication

Multiplies two numbers.

```text
10 × 5 = 50
```

### ➗ Division

Divides the first number by the second.

```text
10 ÷ 5 = 2
```

The calculator also handles division by zero safely.

### `%` Modulus

Returns the remainder after division.

```text
10 % 3 = 1
```

## ⚠️ Error Handling

The calculator handles common input errors such as:

- Invalid menu choices
- Non-numeric input
- Division by zero
- Modulus by zero

Instead of crashing, the program displays an appropriate message and allows the user to continue.

## 🐞 Common Mistakes

While building this project,we must pay attention to:

- Forgetting to convert input strings into numbers.
- Using the wrong arithmetic operator.
- Dividing by zero.
- Forgetting to handle invalid choices.
- Writing all logic inside one large block.
- Creating unnecessary repeated code.
- Forgetting to stop the program when the user chooses Exit.
