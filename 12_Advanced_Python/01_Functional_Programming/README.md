# ⚙️ Functional Programming in Python

Welcome to the **Functional Programming** section of the **Advanced Python** repository.

This module introduces powerful Functional Programming concepts that help you write **clean, reusable, modular, and efficient Python code**.

You'll learn how Python treats functions as first-class objects and how advanced features such as **Generators, Closures, and Decorators** are built on this foundation.

---

# 📚 Topics Covered

## 📖 1. Iterators and Iterables

Learn how Python iterates over data internally.

Topics include:

- What are Iterables?
- What are Iterators?
- Iterator Protocol
- `iter()`
- `next()`
- Custom Iterators
- StopIteration
- Real-world Examples

---

## ⚡ 2. Generators

Learn how to generate values efficiently using the `yield` keyword.

Topics include:

- Generator Functions
- `yield`
- Generator Expressions
- Lazy Evaluation
- Memory Efficiency
- Infinite Generators
- Real-world Applications

---

## 🔒 3. Closures

Understand how inner functions remember variables from their enclosing scope.

Topics include:

- Nested Functions
- Closures
- Free Variables
- Lexical Scoping
- `nonlocal`
- Function Factories
- State Preservation
- Real-world Examples

---

## 🎨 4. Decorators

Learn one of Python's most powerful features for extending function behavior.

Topics include:

- Higher-Order Functions
- Function Wrapping
- Custom Decorators
- `@` Syntax
- Decorators with Arguments
- Multiple Decorators
- Built-in Decorators
- `functools.wraps`
- Real-world Applications

# ⭐ Key Takeaways

- Functions are first-class objects in Python.
- Iterators control how iteration works.
- Generators produce values lazily and efficiently.
- Closures preserve state using enclosing variables.
- Decorators extend function behavior without modifying the original function.
- Functional Programming promotes reusable, modular, and maintainable code.
